# Ticketing Architecture Laravel Portfolio

Projeto de portfólio focado em arquitetura de software com Laravel, aplicando:

- Clean Architecture
- Hexagonal Architecture
- CQRS leve
- DDD tático
- SOLID
- Redis (cache e fila)
- RabbitMQ (mensageria)
- Docker (ambiente reprodutível)

Este repositório será construído por fases com histórico de commits orientado à demonstração técnica.
